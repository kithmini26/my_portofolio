# Vimarshana Kithmini — Portfolio

A personal portfolio site showcasing my background in Software Engineering and Quality Assurance,
built with plain HTML, CSS, and JavaScript — no frameworks, no build step.

**Live site:** https://kithmini26.github.io/my_portofolio/

## Sections
- **Home** — introduction and resume download
- **About** — bio, photo, and core skills
- **Projects** — Loan Approval System with Explainable AI, UTOPIA (civic engagement platform),
  and Smart Library System
- **Certifications** — QA and software testing certifications, with two linked to their actual
  certificate PDFs
- **Contact** — a working contact form (opens the visitor's email app, pre-filled and addressed
  to me, since this is a static site with no backend server)

## Files
- `index.html` — the full page (profile photo is embedded directly inside this file as base64,
  so it always loads correctly regardless of file organization)
- `style.css` — all styling
- `script.js` — footer year and contact form handler
- `Kithmini_CV.pdf` — downloadable resume
- `Introduction_to_Software_Testing.pdf` — certificate
- `What_is_Software_Development.pdf` — certificate

## Tech
HTML5, CSS3 (custom properties, no framework), vanilla JavaScript, Google Fonts (Poppins + Inter).

## Running locally
Just open `index.html` in any browser — no server or build step required.

## Deployment
Hosted for free via GitHub Pages, serving directly from the `main` branch root.
